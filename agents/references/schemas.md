# Schemas

Use when touching `api/v1alpha1/types.go`, loaders, validators, or YAML
examples.

## Rules

- Current API is `gitups/v1alpha1`; it is intentionally still early-stage and
  may take breaking schema changes without an apiVersion bump when maintainers
  request one.
- Keep Gitups-owned package metadata versions at `0.0.1` until maintainers
  explicitly start release versioning. This does not apply to upstream pins
  such as chart versions, `startingCSV`, image tags, OLM releases, or
  Kubernetes API versions.
- Use JSON struct tags only. `sigs.k8s.io/yaml` reads those tags; `yaml:` tags
  drift and are ignored.
- `Provision` stays lean: sources and repository declarations only, plus
  explicit package/resource values. There is no top-level `spec.packages`.
- Empty `spec.sources` and `spec.repositories` are valid so `init` output can
  pass schema validation; `expand` rejects an unfilled scaffold.
- `FullProvision.spec.sources` mirrors `Provision.spec.sources` so render can
  rebuild the catalog without reading `Provision`.
- Placeholder sentinel is fixed: `__GITUPS_PLACEHOLDER__`.
- `{{.Env}}` is allowed only in repository names. It is replaced with
  `spec.envKey`, falling back to `FullProvision.metadata.name`.
- `spec.extends` lets an env Provision inherit a generic base Provision
  (single level only). `load.ProvisionResolved` merges sources and repositories
  into one effective Provision. The advisory trace is written to
  `FullProvision.spec.extendedFrom`.

## Shapes

Minimal `Provision`:

```yaml
apiVersion: gitups/v1alpha1
kind: Provision
metadata:
  name: dsv
spec:
  sources:
    - name: local
      type: filesystem
      path: ../../../gitups-packages
  repositories:
    - name: basic-infra
      type: k8s-gitops-generic
      packages:
        - template: local/olm
        - template: local/metallb
          installMethod: helm
    - name: basic-infra-{{.Env}}
      type: k8s-gitops-env
      repoRef:
        name: basic-infra
        commit: v0.0.1
```

Explicit repeated resources:

```yaml
repositories:
  - name: basic-infra-dev
    type: k8s-gitops-env
    repoRef: {name: basic-infra, commit: v0.0.1}
    packages:
      - template: local/metallb
        resources:
          - template: config
            name: pool-a
            values:
              addressPools:
                - name: pool-a
                  cidrs: [192.168.10.240-192.168.10.245]
          - template: config
            name: pool-b
```

`FullProvision`:

- generated by `gitups expand`;
- sorted topologically by descriptor `dependsOn`;
- uses `spec.packages[*].resolvedValues` as the only render-time value source;
- stores resolved repository placement in `repository` and `renderedPaths.repo`;
- expands each selected unit with `unitType: install|resource`;
- records installs with `installMethod`;
- records resources with `resourceTemplate` and `resourceName`;
- uses `renderedPaths.dir` as `packages/<pkg>/install/<method>` or
  `packages/<pkg>/resources/<template>/<name>`;
- regenerates `spec.placeholders` every expand as advisory metadata.

Core `package.yaml` fields:

```yaml
apiVersion: gitups/v1alpha1
kind: PackageDefinition
metadata: {name: metallb, version: 0.0.1}
spec:
  role: controller | workload
  category: network-lb
  defaultInstall: olm
  defaultResources:
    - template: config
      name: default
```

Install/resource descriptor:

```yaml
apiVersion: gitups/v1alpha1
kind: PackageDescriptor
metadata: {name: helm}
spec:
  renderer: helm
  inputs: []
  dependsOn: [metallb/install]
  hooks: {}
  overlays: []
  helm:
    repo: https://example.invalid/charts
    chart: name
    version: 1.2.3
    valuesTemplate: values.yaml.tmpl
```

Input fields: `name`, `type`, `default`, `enum`, `required`, `sensitive`,
`placeholder`, `placeholderReason`.

## Gotchas

- Descriptor `inputs[].default` is `any`; YAML numbers commonly unmarshal as
  `float64`.
- Dotted input names merge into nested maps. A scalar at a prefix that also
  needs children is an error.
- `placeholder: true` wins over `default`.
- Placeholder reasons are prefix-based; a top-level input can explain nested
  sentinels.
- Package `metadata.name` must match the package directory.
- Descriptor `metadata.name`, when set, must match the unit directory name.
- Env repos with `repoRef` and no packages derive each referenced generic
  package's `defaultResources`; explicit `packages[].resources[]` replaces the
  derived resource list for that package.
